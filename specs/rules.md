# Rules verification registry

**Official Vietnamese edition: unverified.** An official-rules release requires one identified edition and traceable evidence for every shipped rule and datum. Classic C1009 is a candidate comparison baseline. Its product listing supports a few broad mechanics, with detailed procedures still awaiting rulebook review. The prototype uses synthetic values and provisional behavior only.

Vietnamese evidence is pending for every row. When evidence is located, record edition ID, source ID, page or section, paraphrased behavior, discrepancy against the candidate baseline, reviewer and review date. Change a row to verified only after review against the target edition. Conflicts stay open until resolved. Link each resolved row to the affected scenarios and pin the resulting rules profile per match.

Digital choices such as room capacity, seat identity, reconnect and race resolution are specified in [rooms](rooms.md) and [turn state](turn-state.md).
